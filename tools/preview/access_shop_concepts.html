Access Shop block

One block, two blocks wide and two tall like BSP-Core's Trade Post, in the same steel, with a screen showing the admin's message. A player with no main server is offered a free pick first, the same as at a portal. After that the shop sells the tokens its admin listed, for rent or full access, in pieces or coins. Every shop block has its own list; an admin can copy another shop's list on the same server. Switch between the three views under each option.

A: The price list

  • One list, one row per thing on sale: the token, what it opens, rent or full, the price, BUY. Owned things say OWNED.
  • A token offered both ways is two rows, so every price is visible at once.
  • Admin view: the same rows with the price, currency, rent hours and order editable; ADD picks any assigned token.

B: Token cards by kind

  • Tabs SERVERS, PORTALS, WARPS. Each token is a card; picking RENT or FULL on the card shows that price.
  • The block's screen shows the message with the first three tokens' coins under it.
  • Admin view: a 4-wide grid of slots per tab. Click a slot to put a token there and set both prices.

C: List and detail

  • Left: what the shop sells. Right: the one picked, with RENT and FULL side by side, what each costs, and what you hold now.
  • The clearest for a first-time buyer: one decision at a time, the price next to the BUY key.
  • Admin view: the same two panes; the right one edits the picked token, plus the message and Copy from.
