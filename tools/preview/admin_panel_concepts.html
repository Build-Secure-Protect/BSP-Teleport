Teleport Admin Panel Concepts

The admin panel for BSP-Teleport, opened with /bsptp admin or from an ADMIN tab the band shows to admins. It covers four jobs: the settings in bsp_teleport-server.toml that admins change often, the warps, the servers of the network (who is where, evacuate, send everyone home) and the players (bring, go to, where they logged out). Drawn in the Holo HUD style with BSP-Core's violet operator border. Three layouts, same content.

State:

The three layouts

What all three share

  1. Settings change the live server config and save it, so a restart keeps them. Each value shows its name, its meaning in one line and - / + or a switch. The totem-driven numbers (home slots, Swift Travel) are read-only here with a note that the totem sets them.
  2. Warps: set a warp where the admin stands (name, cost, restricted), move or delete one, and see which server it is on. The band's WARPS tab shows the same list to players.
  3. Servers: each server of the network with its player count, up or down, and three actions: bring everyone here (the restart evacuation, saves their /back), send everyone to another server, and go there. This server is marked.
  4. Players: everyone on the network with their server; bring, go to, or go to where they last logged out.
  5. Status line at the bottom: storage, Redis, this server's name.
  6. Only BSP-Core admins (or the bsp_teleport.admin node) can open it; moderators see it read-only, as on BSP-Core's panel.

Decided (owner, 2026-10-15)

  1. Layout: C, Map.
  2. Settings on the panel: warm-up, cooldown, cancel on damage, cancel on move, skip-cooldown coins, raid distances, random teleport on/off and radii, request expiry, global spawn warp. Saved to the config file at once. Credentials stay in the file.
  3. Moderators: read-only.
  4. Opens from: /bsptp admin and an ADMIN tab on the band.
  5. Confirmation: a Yes / No popup before anything that moves more than one player, and before deleting a warp.
