Asking before a home is replaced

Today, Set home with a name you already use (or with an empty box, which means home) moves that home to where you stand without asking. With every slot used and a new name, it says "Delete one first." Each option below asks instead. Every option is shown twice, already asking: once for a taken name, once for a new name with every slot used. Answer it to see the result, or type your own name and press Set home.

A: The popup

Name already used: base
All 3 slots used, new name: tower
  • The same gold box as the delete question. A taken name asks "Move the home Base here?"
  • With every slot used, the box lists your homes. Picking one replaces it with the new name in the same slot.
  • Nothing else on the band works while it shows. Esc or No closes it.

B: The rows answer

Name already used: base
All 3 slots used, new name: tower
  • A taken name turns that row gold, with MOVE HERE and KEEP on it.
  • With every slot used, each row shows REPLACE, and the footer says what will happen, with CANCEL.
  • You see each home's place while you choose.

C: The footer asks

Name already used: base
All 3 slots used, new name: tower
  • The Set home strip turns into the question, the same way a home delete asks in option C of the last set.
  • With every slot used, it shows one key per home to replace, plus KEEP.
  • The smallest change, but the keys get tight with many homes.

Commands (the same for every option)

> /sethome base You already have a home base. [Move it here] [Keep it] > /sethome tower All 3 homes are used. Replace one with tower: [base] [farm] [mine]

Clicking runs /sethome base confirm or /sethome tower replace farm, which players can also type.
