Access Concepts

The access system for BSP-Teleport (D67 to D88): players pick one main server for free, rent or buy the others with Access Token items sold in BSP-Core's shops, see what they hold above the hotbar, get a popup when a door is shut to them, and read a board at spawn that says how many players call each server home. Five visual pieces, three options each. The controls set the example player.

Player:

1. The token items

Twenty registered items, Access Token I to XX, one colour each. A token is a server's symbol: it is sold in the shop as a rent stack or a full stack (the tier is in the stack), it shows above the hotbar, and it marks portals that lead to that server. Four of the twenty colours shown, plus the tooltips of a rent stack, a full stack and an unassigned token.

2. Above the hotbar

What a player holds: gold frame for the main server, turquoise for full access, violet for rented with its countdown. Drawn right of the hotbar's centre, since BSP-Core's Recall card uses the left. The small turquoise slot after the hotbar is the Teleport Band.

3. The two popups

Left: "Access needed", shown when a teleport, portal or warp is refused or the player is bounced on login: the server, the token stacks that grant it, the admin's shop hint, Close. Right: "Choose your main server", shown on the first attempt to enter a restricted server without one: the servers with how many players call them home, Choose, then a confirmation.

4. The Access Board

An admin-only block whose panels join into one screen, like BSP-Core's Score Screen. It lists each restricted server with how many players call it home, and the full and rented counts, refreshed every minute from the shared table. The same rows go to BSP-Core's rotating Score Screens once R8 exists.

5. Assigning tokens (admin)

Where an admin puts a token next to the server, region, portal or warp it is for, and takes a rent or full stack to put in a shop. Drawn as a TOKENS tab on the admin panel.

Picks to make

  1. Token look: A Keycard, B Medallion or C Sigil. Default: A.
  2. HUD: A Row, B Strip or C Column. Default: A.
  3. Popups: A Card, B Sheet or C Banner. Default: A.
  4. Board: A Bars, B Tiles or C Columns. Default: A.
  5. Assigning: A Slots, B Pick-then-place or C Table. Default: A.
