Asking before a home is deleted

On the panel's WARPS tab, Del already asks "Delete the warp market?" with Yes and No. On the band's HOMES tab, Del removes the home straight away. Each option below adds a question there. Press DEL to try it; Esc answers No.

A: The panel's popup

Homes
Set home
  • The band dims and a gold box asks "Delete the home Base?" with Yes and No, the same box as a warp delete on the panel.
  • Nothing else on the band works while it shows. Esc or No closes it.
  • Players and admins learn one question that looks the same everywhere.

B: Press Del twice

Homes
Set home
  • The first press turns the row red and its keys into SURE? and KEEP. SURE? deletes.
  • It goes back by itself after 4 seconds, or when anything else is pressed.
  • Fastest for someone tidying several homes, and nothing covers the list.

C: A question in the footer

Homes
  • The row turns red and the Set home strip at the bottom becomes "Delete Base? This cannot be undone." with DELETE and KEEP.
  • The same way the server access card asks before a main server is chosen.
  • The list stays readable, so the player can see which home they picked.
