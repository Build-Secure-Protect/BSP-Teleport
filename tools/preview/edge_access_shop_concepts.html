Edge Access Shop

A player walks to a world edge linked to another server, says TRAVEL, and has no access there. Today they are sent across, bounced to the lobby, and shown a small "Access needed" banner with no way to buy. These options show what they could see instead, and where an admin sets the prices.

BSP-Teleport owns access tokens, the Access Shop and the TOKENS tab. Options A and B are built there only. Region Guard option C also changes Region Guard's edge question.

Today

The edge move goes straight to the other server. That server sees no access, sends the player to the lobby (BSP-Spawn) and shows the banner: "ACCESS NEEDED: BSP-FROSTWARF", the two token stacks and CLOSE. Each Access Shop sets its own price, so nothing outside a shop knows what a token costs.

Questions each with a default

  1. Check before leaving. Default: yes. BSP-Teleport checks access when the edge move reaches it, so the player stays at the edge and is not bounced to the lobby.
  2. USE NOW at the edge. Default: the trip goes ahead at once, as if they had said TRAVEL again.
  3. Same pop-up everywhere. Default: yes. Every refused server entry (portals, warps, the server switcher, the arrival bounce) uses the new pop-up, not only edges.
  4. Shops lose their own prices. Default: yes. A shop only picks which tokens and which tiers it sells. The price comes from the token.
  5. Shops built before this. Default: their prices are dropped. A token is not for sale until an admin prices it. Shops and the pop-up show "No price set".
  6. Rent length. Default: the token's existing rent hours, shown as days and hours, typed or stepped a day at a time.
  7. Pieces or coins. Default: chosen per tier, as in the shop today.
  8. No price or tier off. Default: the pop-up shows today's banner text (the token and the hint) with no BUY.
  9. No main server yet. Default: the free main-server choice comes first, as today (D82).
